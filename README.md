Python Units 1 and 3 - Practical Test Solutions

Welcome to the repository containing solutions for the Python Units 1 and 3 Practical Test (Set C). This document provides an overview of the scripts included, instructions for running them, and explanations of the core concepts used.

📂 Repository Structure

Q1.py: Demonstrates print function arguments (sep, end), escape characters (\t, \n, \'), multiple variable assignment, and variable swapping.

Q2.py: Covers input/output operations, type casting (int, float), error handling (try-except blocks for ValueError and TypeError), and float-to-integer conversions.

Q3.py: Explores Python data types, type inspection (__name__), floating-point precision checks, boolean logic evaluation, truthy/falsy values, and isinstance checks.

Q4.py: Demonstration of integer division, modulus arithmetic with negative numbers, operator precedence, exponentiation associativity, type inspection, and basic formatting.

Q5.py: Logical operators, conditional eligibility logic, short-circuit evaluation, truthy/falsy values, and augmented assignment operators with type mixing.

Q13.py: Member books report processing, aggregation, conditional grading, and statistics using sets, dictionaries, lists, and tuples.

🚀 Getting Started

Prerequisites

Make sure you have Python 3.x installed on your system. You can check your Python version by running:

python --version


Running the Scripts

You can run any of the individual script files using your terminal or command prompt:

python Q1.py
python Q2.py
python Q3.py
python Q4.py
python Q5.py
python Q13.py


🧠 Core Concepts & Data Structures Breakdown

1. Set (set)

Usage: Used in the member records script to extract and store unique book genres.

Why: Sets automatically eliminate duplicate entries, ensuring each genre appears only once.

2. Dictionary (dict)

Usage: Used to map each member's name to their corresponding book counts and calculated averages.

Why: Dictionaries provide efficient key-value lookups, making it straightforward to associate and retrieve member-specific data.

3. List (list)

Usage: Used for sequential collections, sorted items, and list comprehensions (e.g., filtering members above the overall average).

Why: Lists maintain insertion order, support indexing/slicing, and allow flexible dynamic resizing and mutations.

4. Tuple (tuple)

Usage: Used for storing fixed read-only data pairs, such as the extremes (smallest, largest) of all books.

Why: Tuples provide immutability, ensuring that aggregate boundary values cannot be accidentally modified during execution.

📝 Author & Context

Developed as part of the Python Units 1 & 3 practical curriculum to demonstrate proficiency in core Python data structures, arithmetic operators, type casting, error handling, control flow, and formatted string outputs (f-strings).
